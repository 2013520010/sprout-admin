# 新芽 Sprout Admin — 路线图 Roadmap

> 项目的功能演进规划，帮助使用者与贡献者了解当前进度和未来方向。

## 已实现

| 模块 | 说明 |
|------|------|
| ✅ 工程骨架 | Spring Boot 3 + MyBatis-Plus + Maven，统一配置与分层结构 |
| ✅ 认证授权 | JWT + Redis 无状态认证，Spring Security 6 注解级鉴权 |
| ✅ 系统管理 | 用户 / 角色 / 菜单 / 部门 RBAC 模块 |
| ✅ 日志管理 | 登录日志、操作日志（`@Log` 注解 + AOP 切面） |
| ✅ 代码生成器 | 数据库元数据读取 + Velocity 模板渲染 + zip 打包下载 |

## 规划中

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P1 | 前端管理界面 | Vue3 + Element Plus |
| P1 | 数据字典 / 参数配置 | 通用字典与系统参数管理 |
| P2 | 多租户 | 独立库 / 独立 Schema / 字段隔离三种方案 |
| P2 | 验证码登录 | 图形验证码、短信验证码 |
| P3 | 定时任务 | 任务调度与执行日志 |
| P3 | 操作日志异步化 | 消息队列解耦，降低主链路耗时 |

## 版本历史

- **v1.0.0**：首个版本，包含认证授权、RBAC、日志管理、代码生成器。
